# Tutorials

Below is a gallery of tutorials for writing various basic operations
with Triton. It is recommended that you read through the tutorials in
order, starting with the simplest one.

To install the dependencies for the tutorials:

``` bash
cd triton
pip install -r ./requirements.txt
```

# Tutorial Descriptions:

- The Triton tutorials and how to use them are described at [https://triton-lang.org/main/getting-started/tutorials/index.html](https://triton-lang.org/main/getting-started/tutorials/index.html).
- The Gluon tutorials and how to use them are described at [https://triton-lang.org/main/getting-started/tutorials/gluon/index.html](https://triton-lang.org/main/getting-started/tutorials/gluon/index.html).
